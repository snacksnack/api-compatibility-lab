## False breaks

Every `breaking` finding is adjudicated by hand against the changelog for the span, in `scoring/adjudication.json`. A verdict of `documented` means a published change explains it; `undocumented` means the difference is real and Stripe did not write it down; `false-break` means this tool is wrong.

Read that as *no false breaks observed* rather than as a rate measured at scale: the denominator is 62 findings over 38 replayed steps in four workflows. A corpus with more endpoints — especially list endpoints, where account state can masquerade as a version difference — is where this number earns its keep.
